# Repositorios autorizados

Este directorio sólo modela el conjunto operativo actual del proyecto y funciona como registro dinámico para el corte actual. Los repositorios se gestionan a partir de la autorización del profesor y no a partir de un inventario fijo.

## Alcance vigente

- Transversales: api-gateway, worker, workflow, front
- Catalog: catalog-db, catalog-api, catalog-portal
- Sales: sales-db, sales-api, sales-portal
- Infra previa: infra-postgres, infra-mongo, security

Cada repo se considera un componente real del sistema distribuido que se va a extraer o conectar, no un placeholder.
